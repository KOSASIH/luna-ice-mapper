# Build Scripts

Build automation for all Luna Ice Mapper software components.

## Usage

```bash
# Full build (all components)
bash scripts/build/build.sh --all

# Firmware only
bash scripts/build/build.sh --firmware

# Python packages only
bash scripts/build/build.sh --python

# Ground station
bash scripts/build/build.sh --ground-station
```
