# Contributing to Luna Ice Mapper Web Platform

Thank you for your interest in contributing to the **Luna Ice Mapper** scientific web platform!

## Code & Standards Guidelines

- **TypeScript**: Strict mode enabled. Ensure all components and functions are typed.
- **Styling**: Use Tailwind CSS utility classes and dark space color variables (`#030712` space, `#38bdf8` ice accent).
- **Data Compliance**: Scientific datasets must adhere to NASA Planetary Data System 4 (PDS4) standards.
- **Accessibility**: Ensure WCAG 2.1 AA contrast ratios for UI text elements.

## Pull Request Process

1. Fork the repository and create your feature branch: `git checkout -b feature/my-feature`
2. Ensure `npm run lint` passes without errors.
3. Submit a pull request describing the changes and scientific or UI impact.
